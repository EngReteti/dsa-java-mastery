# Array Folder Recap

## What this folder covers

Twenty five problems, covering the full spread of core array techniques, from simple traversal through two pointer manipulation, prefix sums, sorting based approaches, and hash based tracking.

## Problems, technique, and why each one was chosen

Two Sum uses a hash map to find complements instantly. It was included first because almost every technical interview begins with a warm up question at this level, and it introduces the habit of trading extra memory for faster lookups.

Contains Duplicate uses a hash set for instant presence checking. It reinforces the same lookup habit from Two Sum in an even simpler form.

Remove Duplicates from Sorted Array and Remove Element both use in place two pointer overwriting. They were chosen to build comfort with modifying an array without creating a new one, a constraint interviewers often add deliberately.

Search Insert Position introduces binary search early, since this technique reappears constantly in harder problems later.

Plus One and Merge Sorted Array practice careful index handling and digit or value comparisons, skills that matter more than they seem, since small indexing mistakes are one of the most common ways candidates lose interview points.

Pascal's Triangle practices building each result from the previous one, a pattern that shows up again in dynamic programming later.

Best Time to Buy and Sell Stock, Single Number, and Majority Element were chosen together because they all rely on tracking one or two running values in a single pass, rather than nested loops, which is exactly what interviewers are checking for when they ask these.

Missing Number and Find All Numbers Disappeared in an Array use the relationship between array values and their indexes to avoid extra memory entirely, a favorite trick question style at companies that specifically care about space efficiency.

Move Zeroes, Container With Most Water, Trapping Rain Water, and Rotate Array were grouped to build two pointer intuition from multiple angles, shifting elements, shrinking inward from both ends, and reversing sections of an array.

Maximum Subarray, using Kadane's algorithm, was included because it is one of the single most frequently asked array questions across the entire industry, and it teaches the important idea of resetting a running total instead of always accumulating.

Product of Array Except Self was chosen specifically because the obvious solution, using division, is usually the wrong one in an interview setting, and this problem tests whether a candidate reaches for prefix and suffix products instead.

3Sum and Search in Rotated Sorted Array represent the jump into medium difficulty thinking, extending two pointer logic and binary search into situations that are not immediately obvious.

Merge Intervals was included because interval based problems appear constantly in real systems involving scheduling, booking, or calendar logic, not just as an abstract exercise.

Longest Consecutive Sequence and Subarray Sum Equals K close out the folder with hash based thinking, specifically testing whether a candidate avoids brute force nested loops when a hash set or hash map would solve the same problem far faster.

## Where this applies in real interviews

Two Sum and Contains Duplicate are common in phone screens and online assessments across nearly every company worldwide.

Maximum Subarray appears so frequently that it is often considered a baseline expectation rather than an impressive answer on its own.

Container With Most Water and Trapping Rain Water are common at Google and Meta, where the interviewer is often more interested in hearing the reasoning behind pointer movement than the final answer itself.

Product of Array Except Self is a strong signal question at Microsoft and Amazon.

3Sum and Search in Rotated Sorted Array are medium difficulty staples at Meta, Amazon, and many fast growing technology companies.

Merge Intervals is common at companies building scheduling, logistics, or booking systems.

Longest Consecutive Sequence and Subarray Sum Equals K test whether a candidate defaults to hash based thinking under pressure.

## Preparing for interviews in Kenya and worldwide

Very few companies hiring directly within Kenya run strict algorithmic interviews of this style, local hiring tends to weigh practical coding ability and system understanding more heavily. Where this array preparation becomes genuinely valuable for a developer based in Kenya is as a gateway into two specific paths, remote positions at international companies, which almost always run standard algorithmic interviews regardless of where the candidate is located, and international hiring platforms or direct applications to global technology companies, where the interview format is identical to what any candidate elsewhere in the world would face. In short, this preparation matters most in Kenya as the entry point into global remote opportunities, rather than as local interview practice.

## Priority list if time is limited before an interview

Two Sum, Maximum Subarray, Container With Most Water, 3Sum, Search in Rotated Sorted Array, and Subarray Sum Equals K together cover almost every pattern likely to appear in a real interview, and are worth revisiting first if time is short.
